# 截图目录 / Screenshots

README 中的界面截图存放在本目录，文件名与 README 表格一致：

- `totp.png` — 2FA TOTP 验证码页
- `database.png` — 数据库浏览页（Turso / MySQL / PG 任一）
- `sftp.png` — SFTP 文件管理页
- `remote.png` — 远程检测页（安全检测结果为佳）
- `password.png` — 密码加密页
- `s3.png` — S3 对象存储页

截图约定：
- 100% 缩放、浅色或深色主题任选其一并保持统一；
- 内容注意脱敏（主机名 / IP / 账号可打码或用示例数据）；
- 建议宽度 ≥ 1200px，PNG 格式，单张 ≤ 500KB（可用压缩工具过一遍）；
- 每次发版前检查截图是否与当前界面一致（见根目录 RELEASE_CHECKLIST.md）。
